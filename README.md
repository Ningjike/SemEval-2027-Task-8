# StereoQueerEval（SemEval 2027）

本仓库研究多语言 YouTube 评论中的 LGBTQIA+ 刻板印象、仇恨言论及仇恨对象识别。包含数据准备、对比学习、API 基线、指令微调、英文翻译与波斯语合成数据实验。

## 任务与数据

| 子任务 | 输出 | 本地指标 |
| --- | --- | --- |
| A：刻板印象 | `no` / `yes` | 两类 Macro-F1 |
| B：仇恨言论 | `no` / `yes_implicit` / `yes_explicit` | 三类 Macro-F1 |
| C：仇恨对象 | `group` / `individual` 加九个可多选身份 | 0.5 × 范围 Macro-F1 + 0.5 × 九个身份正类 F1 的平均 |

C 只对真实标注为仇恨的样本计算。九个身份为 `l, g, b, t, q, i, a, nb, lgbtqia+`。

原始数据包括 EN 2,989、IT 2,400、NL 2,238 条训练样本，以及 FA 100 条开发样本。仓库中的分组多语言划分为训练 6,106 条、验证 1,521 条；该验证集含 790 条仇恨样本。单语言和留一语言划分也由数据准备 Notebook 生成。原始数据受使用协议约束，不应随仓库分发；获取方式、字段和条款见 [data/README.md](data/README.md)。

## V1 SCL/ V2 MoCo /SFT
### 数据与划分
使用 EN、IT、NL 共 7,627 条样本，按语言、原始视频标题和描述构造上下文分组，再按约 **8∶2** 划分训练集与验证集。当前训练和评估均使用 `grouped_multilingual`。

| 数据 | 样本数 | 用途 |
| --- | ---: | --- |
| 训练集 | 6,106 | 训练 A/B；C 使用其中的仇恨样本 |
| 验证集 | 1,521 | 每轮验证、选择最佳 checkpoint，以及训练后的评估 |
| 验证集中的仇恨样本 | 790 | C 的对象识别评估 |
| FA 开发集 | 100 | 单独保留，未用于当前训练和结果汇报 |

### 方法与训练配置
编码器为 `FacebookAI/xlm-roberta-base`，输入按照 `[COMMENT] 评论 [TITLE] 标题 [DESCRIPTION] 描述` 拼接，截断至 512 tokens。编码器输出经均值池化、dropout 和任务分类头得到预测。A/B/C 分别训练模型。
- **v1：批内 SCL**，在当前 micro-batch 内构造同标签正例。
- **v2：MoCo-SCL**，使用动量模型和带标签的历史队列扩展对比候选。

以下为当前代码配置，每个版本内 A/B/C 一致：

| 参数 | v1 | v2 |
| --- | ---: | ---: |
| epochs | 8 | 3 |
| batch size | 8 | 4 |
| gradient accumulation | 2 | 4 |
| 有效 batch size | 16 | 16 |
| eval batch size | 8 | 8 |
| learning rate | 2e-5 | 2e-5 |
| weight decay | 0.03 | 0.01 |
| SCL weight | 0.1 | 0.1 |
| temperature | 0.1 | 0.1 |
| queue size | — | 4096 |
| momentum | — | 0.999 |

共同设置：seed=42、max length=512、dropout=0.1、projection dim=128、AdamW、warmup ratio=0.1、线性学习率调度、CUDA 混合精度。A/B 按验证 Macro-F1 保存最佳 checkpoint，C 按验证 Target exact match 保存。
